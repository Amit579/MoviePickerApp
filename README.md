# 🎬 MoviePickerApp

A modern **SwiftUI + MVVM + Combine + SwiftData** app that helps users pick the perfect movie based on their mood and genre — powered by **The Movie Database (TMDB) API**.

---

## 🚀 Features

- **Mobile Number Authentication**
  - Signup & Login using mobile number (session stored for 72 hours)
  - Logout and session management included

- **Movie Recommendation**
  - Fetch movies by selected genre from TMDB API
  - Like / Skip system to personalize recommendations
  - Cached preferences via SwiftData

- **Profile Management**
  - View user profile
  - Edit user info and logout

- **Modern Architecture**
  - MVVM pattern with Combine
  - SwiftData for persistence
  - Clean modular structure
